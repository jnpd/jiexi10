# 配电变压器规格书怎么拆出产品行？（业务解析思路）

> 本仓库现在先重点解释**怎么读懂一份客户规格书、怎么找出产品系列、为什么拆出多个容量产品、参数如何归属到对应产品**。不要求先懂后端、API、数据库或任何编程。

## 先看这一份（这是主要文档）

📘 **[解析思路：我是怎么从规格书拆出产品行和参数归属的](docs/解析思路_我是怎么从规格书拆出产品行和参数归属的.md)**

这份文档以实际两份 EDM 变压器 PDF 为例，逐步说明：

1. **先认系列**：相数、额定高压、额定低压分别从哪些原文定位；为什么 400/230V 不代表两种低压产品。
2. **再拆容量**：为什么第12页列出的50/75/100/160/200/250/315/500/630kVA形成9行具体规格。
3. **核对范围**：为什么“标准支持9容量”和“Scope特别写75kVA”要同时保留；为什么不能直接推成已采购9款。
4. **判断参数归属**：哪些适用于全系列、哪些分容量档、哪些只属于75kVA。
5. **填写参数**：为什么500kVA阻抗是≤5.5%，但其200W/910W损耗不能从75kVA继承；哪些应该写待定。
6. **生成产品名与表格**：一条产品行怎样从分散章节汇聚完整参数；最终每产品一个Sheet仅是呈现结果。

**完整业务原则：先认系列，再拆容量；先看适用范围，再分配参数；不确定不补值，最后逐产品成表。**

## 本次样本统计：一定注明“什么口径”

| 原始文档 | 产品大类 | 标准列出容量数 | 备注 |
|---|---|---:|---|
| EDM 三相11kV/0.4kV | 1 | 9 | Scope另特别指向75kVA |
| EDM 三相22kV/0.4kV | 1 | 9 | Scope另特别指向75kVA |
| 合计 | **2** | **18个技术规格** | 不能据此确认实际采购18个型号/台数 |

本次《参数确认表》有31个字段：它决定**每张产品参数表有哪些行**，不能反过来决定“有多少产品”。
