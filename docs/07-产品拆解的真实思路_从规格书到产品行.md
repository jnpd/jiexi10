# 07｜我到底是怎样读一份规格书的：产品拆解思维模型

> **这是一份“思路文档”，不是开发设计。** 先讲我脑子里如何判断，再决定以后怎样把判断交给AI和业务规则。  
> 对应案例：`Attachment 1.1-Transformers 3P 11kV-备注版.pdf`、`Attachment 1.2 Transformers 3P 22KV-备注版.pdf`。  
> 已有更完整的解释可参阅：[解析思路_我是怎么从规格书拆出产品行和参数归属的.md](解析思路_我是怎么从规格书拆出产品行和参数归属的.md)。

## 一、我看的是四类事实，而不是直接填表

拿到PDF，我把文字划分为下面四类，每一类解决不同问题。

| 事实类型 | 我问自己的问题 | 用途 | 示例 |
|---|---|---|---|
| **身份事实** | 这是什么相数、额定高压、额定低压的变压器？ | 判断“产品大类” | 3P / 11kV / 400-230V |
| **枚举事实** | 这个大类到底包含哪些容量？ | 决定是否产生新“产品行” | 50、75、100、160、200、250、315、500、630kVA |
| **约束事实** | 一句话适用于哪些产品？数值是限值还是允差？ | 将要求分配到正确产品 | ≤315kVA阻抗≤4%；75kVA空载限值200W |
| **范围事实** | 标准支持的范围与本次采购范围是不是一回事？ | 决定报表的统计口径 | §5.5.1列9个，Scope强调75kVA |

**我的真实顺序**：
```text
先确定：这个文件讨论谁？
      ↓
再确定：这个系列列出哪些容量？
      ↓
核实：容量与相数、高低压之间有没有明确关系？
      ↓
展开：每一种有证据支持的四维组合成为产品行
      ↓
找齐：各章节所有技术要求，并给每个要求加“适用对象”
      ↓
归属：逐产品判断哪些要求可以继承，哪些不能继承
      ↓
表达：保存值、性质、原文；未知填待定，冲突留待确认
      ↓
输出：按模板字段顺序为每个产品形成完整参数表
```

**不是**“先看到75kVA的200W，就找出一个名叫‘铜-75kVA…’的产品”，更**不是**“从PDF里找到9个容量，就给所有9款抄相同损耗”。

## 二、第一遍读：只认“大类”，不数规格

### 看哪里
1. 封面及标题：通常写相数、额定高低压、主要对象。
2. Scope/Foreword：这份文件在什么范围内有效，有没有特定采购容量。
3. Electrical System Parameters、Voltage Ratio：复核封面是否准确，确定哪些是**额定电压**。

### 我实际得出的结论
- 11kV PDF：三相（3P），额定一次电压11kV，二次是三相400/230V，产品分类低压按400V线电压记0.4kV。
- 22kV PDF：三相（3P），额定一次电压22kV，二次同样是400/230V。
- 所以先得到**两个大类**：`3P/11kV/0.4kV` 和 `3P/22kV/0.4kV`。

### 我不拿来新增大类的数字
- 11kV对应的`Um=12kV`、22kV对应的`Um=24kV`：这是**设备最高电压**，不是新增额定高压。
- `400/230V`：在三相四线制下分别代表线电压与相电压；没有明确另一独立低压规格时**不拆成0.4/0.23两个产品**。
- `+5%/+2.5%/0/-2.5%/-5%`：是调压档位，不是5种额定电压产品。
- 频率、损耗、阻抗：进入参数，不是本次定义的“四维产品键”。

**这一遍的产物不是Excel，而是一张「产品大类卡」：源文件、相数、额定高压、额定低压、引用原文、仍有的疑问。**

## 三、第二遍读：只找“容量怎么属于这个大类”

### 看哪里
额定容量、Rated kVA、Ratings、容量表、型号列表、GTP附录。只认**额定容量**，不把电流、重量、耐压等误当成容量。

### 我实际看到了什么
两份PDF第12页§5.5.1都写出9个三相额定容量：
`50、75、100、160、200、250、315、500、630 kVA`。

这里的关键不只是出现了9个数字，而是**这个容量列表在讲当前三相变压器系列的额定容量**。因此可在“技术标准全系列”口径下按容量展开。

### 为什么不是随便笛卡尔相乘
如果一份新文件分别列出`11kV,22kV`和`50kVA,75kVA`，但没有说明容量与电压如何搭配，我**不会**直接生成四个组合。必须有文字“以上两种电压均覆盖这些容量”、或清楚的行列表等依据。

遇到一个文件里既有单相又有三相，也必须先按不同相数分离，再分别找其容量列表。

**这一遍产物是「系列—容量关系表」，每一种容量的归属要有原文依据。**

## 四、第三遍读：区分“标准系列”与“实际指定”

EDM文件中出现一个特别重要的现象：
- 第5页Scope特别写75kVA；
- 第12页§5.5.1列出9个容量；
- 11kV文件第24页Annex A标题明确为75kVA；
- 22kV文件第24页Annex A在容量处留空待填写。

这不是在要求我“强行二选一”；我会同时记录：

| 口径 | 代表什么意思 | 这两份文件的解释 |
|---|---|---|
| **标准系列** | 文件讲到的技术上可支持/可选的规格 | 每份9个，合计18个技术规格 |
| **明确规格** | Scope、专属技术数据表特别针对的规格 | 两份Scope均特别指向75kVA |
| **已确认采购** | RFQ、PO、经确认的采购范围中真正要求的规格 | **仅凭这两份PDF不能确定** |

因此“18个产品”是**按标准容量展开的产品规格数**，不是采购型号数、更不是采购台数。

这是整体判断里最容易漏掉的一层。今后新客户文件要保留“我按哪个口径统计”的说明。

## 五、第四遍读：把全文参数改写成“有适用条件的要求”

我不是直接把数值填进产品，而是给每条原文问题打五个标签：

1. **参数名称**：是什么？绕组材质/阻抗/损耗/频率/噪声/安装方式……
2. **实际值或要求值**：铜、50Hz、200W、≤4%。
3. **数值性质**：设计要求、上限/下限、厂家待报、保证值、测试偏差、测量结果。
4. **适用对象**：全系列？哪个容量区间？一个明确容量？特定相数/电压？
5. **依据**：哪个文件、PDF第几页、哪个条款/表格/批注。

### 用真实例子说清楚

| 原文线索 | 我在脑中翻译成哪种要求 |
|---|---|
| §7.2绕组铜线/铜带，适用于所有容量 | `材质=铜；适用=该文件所有相应产品` |
| §5.3频率50Hz | `频率=50Hz；适用=本三相电压系列` |
| §5.8.1容量≤315kVA阻抗不超过4% | `阻抗上限=4%；条件=容量≤315kVA` |
| §5.8.1 500kVA阻抗不超过5.5% | `阻抗上限=5.5%；条件=容量=500kVA` |
| §5.8.1 630kVA阻抗不超过6% | `阻抗上限=6%；条件=容量=630kVA` |
| §6.1/6.2 75kVA空载200W、负载910W | `两种损耗规范上限；条件=容量=75kVA` |
| §6.2允许损耗+10% | `测试允差=+10%；不是额外的W损耗值` |
| Annex A “Vendor to state for each rating” | `保证值由厂家填；现在不能捏造` |

**关键判断**：`+10%`虽然也是“损耗相关数字”，但它与`200W`回答的是不同问题——一个是允差，一个是损耗要求。不能混填。

## 六、第五遍读：现在才“一条产品、一条产品”地分配参数

以11kV文件中的500kVA为例：

```text
产品身份 = 3P + 11kV + 0.4kV + 500kVA
材质：所有额定容量都是铜吗？                  是 → 铜
频率：这个系列要求50Hz吗？                   是 → 50Hz
阻抗：≤315kVA的4%上限覆盖500kVA吗？          否 → 不继承
阻抗：500kVA专门写了5.5%上限吗？              是 → ≤5.5%
空载：200W是哪种容量？                      75kVA → 500不继承 → 待定
负载：910W是哪种容量？                      75kVA → 500不继承 → 待定
```

于是形成显示名称：
`铜-500kVA-11kV-0.4kV-空载待定-负载待定-5.5%-50Hz`。

注意**名称为客户格式做了简写**；参数明细里必须保留`≤5.5%`是“规范上限”这一事实。

75kVA则会满足“≤315kVA阻抗上限4%”，同时匹配75kVA专有的损耗数值；630kVA会匹配阻抗≤6%，但找不到它自己的空载/负载W值，因此仍需待定。

这说明**一份PDF只需要把通用、分档和专属参数整理清楚，再让各产品逐项匹配**。无需假设PDF里有9张填好的完整参数表。

## 七、第六遍读：从结果反向检查我有没有理解错

我的检查不是仅看Excel漂亮不漂亮，而是逐个反问：

1. 这条产品的“四维身份”有原文证据吗？
2. 如果我删掉这一容量，是否因为原文没有它？有没有遗漏列出的容量？
3. 参数是原文明确通用，还是我错误地把一个产品专属的值套给全系列？
4. 有没有将Um当额定高压、把400/230V拆两款、把±10%允差当W值？
5. 有没有将一份PDF的来源引用到另一份PDF的产品中？
6. 标准系列9个和Scope75的矛盾是否解释清楚？有无把标准系列写成采购数量？
7. 模板有多少字段，是否每一行产品都具有全部字段（无值也保留）？

这才是“识别正确”的含义。

## 八、以后遇到陌生文件，靠什么保持这套思路稳定

**不变的是判断顺序，而不是客户文件格式。**

| 复杂情况 | 采用的判断 |
|---|---|
| 一份PDF只有一个额定电压和一个容量 | 一大类、一具体规格 |
| 同一系列给N种容量 | 一大类、N个具体规格 |
| 文件包含两个明确电压系列，容量各不一样 | 先分系列，再分别展开，按文件来源计数 |
| 同时出现1P与3P | 按相数先分开，再找各自容量 |
| 一份PDF多个电压但没有容量配对关系 | 先标“组合待确认”，不能把集合自动相乘 |
| 有铜/铝可选，但四维主键完全相同 | 当前四维识别仍是同一规格；是否算独立报价变体需另约定 |
| 客户标准容量中有模板参考值之外的容量 | 保留客户容量、指出差异，不擅自删除 |
| 扫描件/批注与正文冲突 | 保留证据和冲突，先不形成单一确定结论 |

## 九、这一思路最终产生哪几张“中间业务表”

我希望先能看到以下中间成果，再允许生成最终Excel：

1. **文档认识卡**：文件在谈什么、有什么范围、证据在哪里。
2. **系列清单**：相数、额定电压、容量归属关系。
3. **产品行清单**：四维去重之后的一行一产品。
4. **参数规则清单**：每一条原文要求的“值+性质+适用对象+证据”。
5. **逐产品归属清单**：哪条规则真的适用于哪条产品。
6. **异常/待确认清单**：不确定组合、未提供值、原文与批注冲突、模板差异。
7. **最终产品参数表**：每个产品独立完整字段。

这是下一份文档要“落地”的对象，而不是先上框架。

---

**一句话：先认系列，再拆容量；先问参数适用于谁，再决定它填进哪一行；不确定不编造，最后反向核对原文。**
