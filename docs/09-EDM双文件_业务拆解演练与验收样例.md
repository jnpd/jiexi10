# 09｜用EDM两份真实PDF演练：从原文到18条产品，再到各自参数

> 这是业务推理的**验收样例**：任何人都可以拿它回答“我为什么得到这18行”“某个数值为什么只归属某些行”。内容依据客户此前提供的两份PDF。不要把标准系列规格数当采购数量。

## 0. 输入资料和明确的目标

输入：
- `Attachment 1.1-Transformers 3P 11kV-备注版.pdf`；
- `Attachment 1.2 Transformers 3P 22KV-备注版.pdf`；
- `参数确认表0929(1)(1).xlsx`（本次模板是31个参数字段）。

这次选择的导出口径：**技术标准列举的所有额定容量规格（STANDARD_SERIES）**。

输出应为：**2个独立的Excel，每个Excel有9个产品Sheet，每个Sheet保留31个模板字段**。如果业务上切换到“客户本次明确规格/采购订单确认”口径，数量需要重新按证据判定。

## 1. 先识别“产品大类”：原文在哪里

| 资料 | 原文证据 | 解读 | 易错点 |
|---|---|---|---|
| 11kV PDF第1/5页标题 | THREE-PHASE, RATED VOLTAGE 11 kV/230-400 V | 三相 / 额定高压11kV / 低压三相400/230V | 不把230V认作另一低压型号 |
| 11kV PDF第11页§5.3 | nominal primary 11kV、400/230V、50Hz | 正文复核标题；产品类键为`3P/11/0.4` | 频率是参数，不形成第二系列 |
| 11kV PDF第11页§5.3.3 | Um 12kV | 设备最高电压（绝缘条件） | 不是额定12kV产品 |
| 22kV PDF第1/5、11页 | three-phase 22kV/230-400V | 第二个大类`3P/22/0.4` | 不与11kV混成同一大类 |
| 22kV PDF第11页§5.3.3 | Um 24kV | 设备最高电压 | 不是额定24kV产品 |

第一关结果：11kV文件1个大类，22kV文件1个大类，共2个大类。

## 2. 找到大类里的容量：第12页§5.5.1

两份文件均列：

```text
50, 75, 100, 160, 200, 250, 315, 500, 630 kVA
```

我们已经确定每份文件对应一个三相额定高低压大类，所以这9个额定容量能够分别归入各自的**标准技术系列**。它们不是从《参数确认表》推断出来的，也不是从75kVA损耗表外推出来的。

### 实际形成的18条产品行（按文件分别）

| 行 | 11kV文件：四维唯一产品 | 22kV文件：四维唯一产品 |
|---:|---|---|
| 1 | 3P / 11kV / 0.4kV / 50kVA | 3P / 22kV / 0.4kV / 50kVA |
| 2 | 3P / 11kV / 0.4kV / 75kVA | 3P / 22kV / 0.4kV / 75kVA |
| 3 | 3P / 11kV / 0.4kV / 100kVA | 3P / 22kV / 0.4kV / 100kVA |
| 4 | 3P / 11kV / 0.4kV / 160kVA | 3P / 22kV / 0.4kV / 160kVA |
| 5 | 3P / 11kV / 0.4kV / 200kVA | 3P / 22kV / 0.4kV / 200kVA |
| 6 | 3P / 11kV / 0.4kV / 250kVA | 3P / 22kV / 0.4kV / 250kVA |
| 7 | 3P / 11kV / 0.4kV / 315kVA | 3P / 22kV / 0.4kV / 315kVA |
| 8 | 3P / 11kV / 0.4kV / 500kVA | 3P / 22kV / 0.4kV / 500kVA |
| 9 | 3P / 11kV / 0.4kV / 630kVA | 3P / 22kV / 0.4kV / 630kVA |

“18”仅表示两份文件各自列出的**标准技术规格数相加**，不代表订单中有18种确认采购的产品。

## 3. 为什么要单独看Scope和附录

| 文件 | Scope第5页 | §5.5.1第12页 | Annex A第24页 | 我得到的判断 |
|---|---|---|---|---|
| 11kV PDF | 75kVA | 9个容量 | GTP表标题明确75kVA | 标准系列9种；Scope/附录特别指向75 |
| 22kV PDF | 75kVA | 9个容量 | GTP表容量留空待填 | 标准系列9种；Scope特别指向75；GTP实际提报容量待定 |

这里不能简单说“第12页才对”或“第5页才对”：不同章节在回答不同问题。
- **第12页说可以有哪些额定容量**。
- **Scope/附件说这份规格对哪些具体项目内容更有针对性**。
- **是否买这些型号以及买几台，需要正式采购范围**。

所以全系列9个Sheet是当前**明确选定的技术规格展开方式**，不是经确认的采购需求。

## 4. 先提炼规则，再将规则分配给具体产品

两份文档要**分别**提炼同类型规则，不能让22kV引用11kV来源。

| 规则 | 原文位置 | 规则归属 | 数值性质 |
|---|---|---|---|
| 绕组材质铜 | 第14页§7.2 | 本系列所有容量 | 材质要求 |
| 频率50Hz | 第11页§5.3 | 本系列产品 | 额定频率 |
| 阻抗不超过4% | 第12页§5.8.1 | 容量≤315kVA | 规范上限 |
| 阻抗不超过5.5% | 第12页§5.8.1 | 容量=500kVA | 规范上限 |
| 阻抗不超过6% | 第12页§5.8.1 | 容量=630kVA | 规范上限 |
| 空载200W | 第12页Table 1、第13页Table 3.1 | 容量=75kVA | 规范最大损耗值 |
| 负载910W | 第12页Table 1、第13页Table 3.1 | 容量=75kVA | 规范最大损耗值 |
| 最大噪声49dB(A)，0.3m | 第13页Table 3.1 | 容量=75kVA | 容量专属上限 |
| 损耗的+10% | 第13页Table 3.2 | 按该表可接受偏差范围 | 测试允差，不是W值 |
| 损耗供应商逐规格填报 | 第26页Annex A | 各报价额定容量 | 厂家待提供的保证值 |

### 第一次完整归属示例：75kVA

```text
四维身份：三相 + 11kV + 0.4kV + 75kVA
适用材质 = 铜
适用频率 = 50Hz
阻抗 = ≤4%（因为75≤315）
空载 = ≤200W（原文给出75kVA专属上限）
负载 = ≤910W（同样是75kVA专属上限）
最大噪声 = 49 dB(A) / 0.3m
显示名称：铜-75kVA-11kV-0.4kV-空载200W-负载910W-4%-50Hz
```

### 第二次归属示例：500kVA

```text
四维身份：三相 + 11kV + 0.4kV + 500kVA
材质 = 铜
频率 = 50Hz
阻抗 = ≤5.5%（不能采用≤315kVA那档的4%）
空载W = 待定（75kVA的200W不能继承）
负载W = 待定（75kVA的910W不能继承）
显示名称：铜-500kVA-11kV-0.4kV-空载待定-负载待定-5.5%-50Hz
```

### 第三次归属示例：630kVA

```text
四维身份：三相 + 11kV + 0.4kV + 630kVA
材质 = 铜
频率 = 50Hz
阻抗 = ≤6%
空载W = 待定
负载W = 待定
显示名称：铜-630kVA-11kV-0.4kV-空载待定-负载待定-6%-50Hz
```

对22kV文档按完全相同的判断方法，但**读取22kV自身的原文**；不能偷懒直接复制11kV的原文证据。

## 5. 怎样填每一个产品的31项参数

**重要：模板“字段列表”和“源PDF提供的参数值”不是同一个东西**。

1. 首先把本次《参数确认表》的**全部字段、顺序、单位**复制为每个产品的参数框架。
2. 对每个字段，看看前面归属规则有没有适用于该产品的来源。
3. 有则填“原文要求值+性质+来源”；没有就“未提供”。
4. **W绝对损耗、百分比测试允差绝不能填到同一个类型的字段中**，即使它们都和“空载损耗”相关。
5. 对于“Vendor to state”，显示“待供应商提供”；冲突的展示两个备选并提示待确认。
6. 不在《参数确认表》参考值范围内的160kVA仍保留产品行，在差异报告里指出。

## 6. 这次按什么标准判断结果“正确”

| 验收问题 | 正确结果 |
|---|---|
| 大类数？ | 11kV一个、22kV一个，共2大类 |
| 标准系列具体规格数？ | 每份9个、合计18个 |
| 每份Excel的Sheet数？ | 技术标准全系列口径下各9个 |
| 每个Sheet的参数字段数？ | 本次模板31个字段（包括待定） |
| 75kVA损耗？ | 空载200W、负载910W，注明“规范最大值” |
| 50/100/160/200/250/315/500/630kVA损耗W？ | 原文未列出对应具体值时均待定 |
| 阻抗为什么不同？ | ≤315kVA档4%；500kVA档5.5%；630kVA档6% |
| 是否另有额定12kV/24kV系列？ | 不从Um产生新系列 |
| 400/230V是否两款产品？ | 同一三相低压系统，不按相电压拆两款 |
| 采购是否确定18种？ | 否，缺少RFQ/PO确认 |
| 160kVA与模板标准容量不一致？ | 保留该规格并标示差异 |
| PDF批注和正文不一致？ | 标记待确认，不默默替换 |

## 7. 把这份样例作为未来新客户的比较依据

新客户文件可能不是9个容量，也可能同时包含多个相数、电压和不同产品系列。**不要为了让输出看起来像EDM就强行凑9个**。真正应该迁移的是：

```text
产品大类识别 → 容量归属 → 范围口径 → 产品行 → 原文技术规则
→ 逐产品适用性判断 → 参数完整性/冲突核对 → 独立Excel
```

要检验一份新文件能不能被稳定解析，**先对照每一环能否留下可解释的中间结果**，再检查最终Excel。
